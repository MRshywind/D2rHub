快速入门

欢迎使用 D2RHub。这是一款专为暗黑破坏神 2 重制版设计的现代化多账号管理与启动工具。

  • 在“账号”页面添加您的战网账号。
  • 在“设置”页面配置游戏路径与战网客户端路径。
  • 点击账号卡片上的“启动”按钮，自动完成账号切换与游戏启动。

路径与配置

为了使 D2RHub 正常工作，需要正确配置游戏与战网的路径。

游戏路径

指向 D2R.exe 所在的文件夹。D2RHub 会通过该路径直接启动游戏，绕过繁琐的战网客户端启动流程（如果已缓存 Token）。

战网客户端路径

指向 Battle.net.exe 所在的文件夹。这用于在令牌过期时自动拉起客户端进行登录更新。

账号与令牌机制

D2RHub 支持战网的离线 Token 机制，实现无感切换账号。

  • 添加账号：输入一个显示名称，便于您识别。
  • Token模式：基于设备本地的离线令牌启动游戏，理论上只要不更换设备就不会过期，无需战网客户端参与。
  • Battle.net模式：通过战网客户端登录机制启动，Token有效期通常在30天左右。过期后需要再次通过战网客户端授权。

启动控制

D2RHub 提供了细粒度的启动参数控制：

  • 等待进程退出：如果当前已有其他账号运行，您可以选择等待它们退出后再启动，或直接强行结束它们。
  • 启动参数：支持自定义命令行参数，如 -txt 或 -direct，可以在全局设置或单个账号设置中配置。
  • 多开支持：D2RHub 已内置多开处理机制，无需借助其他第三方工具或额外软件即可实现多账号同时运行。

OCR 与掉落统计

D2RHub 内置了强大的屏幕 OCR 引擎，用于自动识别游戏内的掉落和场景信息。

  • 在“设置”中启用 OCR 功能，并选择要监控的目标账号窗口。
  • OCR 将会在后台静默运行，识别到的符文和物品会自动记录。
  • 点击主界面的“统计”按钮，可以查看详细的掉落历史和效率分析。

悬浮窗与宠物 (Bongo Cat)

增添游戏乐趣的小部件：

  • 屏幕悬浮窗：可以在游戏上方显示当前的 OCR 状态、掉落总览等实时信息。
  • Bongo Cat：一个可爱的敲击键盘小猫动画，它会根据您的鼠标和键盘操作实时反馈。在“设置”中可以调整其缩放比例和位置。

维护与疑难解答

  • 自动更新：应用内不会直接替换可执行文件。检测到新版本后会打开 Release 安装包下载链接，请下载完整 MSI/NSIS 安装包后手动安装。
  • 战网无法启动：检查“设置 - 路径”中的 Battle.net.exe 路径是否存在，并确认 D2RHub 以管理员权限运行。
  • 账号初始化超时：确认战网已完成登录。若登录窗口未置顶，可手动切回 Battle.net 后继续等待。
  • OCR 未识别：确认目标账号窗口标题与设置一致。需要排查时可临时开启 OCR 调试输出，排查完成后建议关闭。
  • 统计页无数据：统计数据来自本地数据库，只有启用 OCR 并识别到场景切换后才会产生记录。
  • 重置状态：退出 D2RHub 后备份并删除本地数据目录，再重新启动即可重新配置。

数据存储与隐私

D2RHub 的运行数据保存在本机，不会主动上传到远程服务器。常见数据包括：

  • 全局配置：战网路径、游戏路径、存档路径、界面偏好和快捷键设置。
  • 账号数据：账号昵称、启动参数、窗口位置、DPAPI 加密后的 Token 数据和 Battle.net 认证快照。
  • 注册表备份：用于账号切换的 Battle.net UnifiedAuth 快照，仅保存在本机账号目录。
  • OCR 数据：启用调试输出时，会在本机保存裁剪截图和识别日志用于排错。
  • 日志与统计：本地日志、刷图记录和统计数据库。
  • 本地统计 API：统计页面只读取本机数据，不对公网开放。

如需迁移或备份，请复制 D2RHub 的应用数据目录。若要清理隐私数据，请先退出程序，再删除账号目录、日志、OCR 调试截图和统计数据库。
